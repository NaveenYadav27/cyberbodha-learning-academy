## 2. Stack & Architecture Verification

  - Dependencies: 515 packages installed cleanly with `--frozen-lockfile`.
  - Core UI: Radix UI primitives, Lucide React (`0.575.0`), Tailwind CSS v4 (`4.3.3`), Tailwind Merge.
  - Core Router & SSR: `@tanstack/react-router` (`1.170.41`), `@tanstack/react-start` (`1.168.60`), `@tanstack/router-plugin` (`1.168.42`), `@tanstack/react-query` (`5.101.4`).

- **Lockfile Integrity:** `bun.lock` remained completely intact and locked during installation.

### 2.2 Server-Side Rendering (SSR) & Worker Entry Point
- **SSR Entry Wrapper:** [src/server.ts](file:///c:/Users/shadowxlab/OneDrive/cyberbodha/cyberbodha-website/src/server.ts)
  - Exports a standard fetch handler: `export default { async fetch(request: Request, env: unknown, ctx: unknown) }`.
  - Incorporates canonical domain redirect: Requests with `hostname === "www.cyberbodha.com"` are redirected to `https://cyberbodha.com` with HTTP 301, preserving exact path and query string.
  - Dynamically invokes `@tanstack/react-start/server-entry`.
  - Normalizes catastrophic H3 / SSR errors into user-friendly HTML error pages with stack logging via `src/lib/error-capture.ts`.
- **Generated Worker Output:**
  - Build directory: `.output/server/index.mjs`
  - Nitro Preset: `cloudflare-module`
  - Asset Serving: Handled via Cloudflare Workers `ASSETS` binding (`env.ASSETS.fetch(cfRequest)`).
  - Compatibility Date: `2026-11-11`
  - Compatibility Flags: `["nodejs_compat"]`
