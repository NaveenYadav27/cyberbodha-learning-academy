# CyberBodha Foundation

## Outcome
Create a polished Phase 1 foundation for CyberBodha with a live academy home page, representative role dashboards, a responsive design system, and an explicit route/navigation/mock-data blueprint. Keep future platform modules planned rather than pretending they are implemented.

## Build
- Replace the template home screen with the CyberBodha academy experience: brand and tagline, public navigation, featured programs, learning tracks, and clear portal entry points.
- Add focused student, instructor, and admin dashboard overview routes with distinct role-aware navigation and realistic illustrative data.
- Establish reusable layout and dashboard primitives, accessible responsive navigation, and semantic dark-navy/red/cyan design tokens.
- Document the planned sitemap, route hierarchy, role navigation, layout boundaries, and mock-data contracts for incremental development.
- Add route-specific metadata; do not connect external services, authentication, persistence, labs, or AI in this phase.

## Verification
Run the existing routing tests, review the preview diagnostics, and exercise the home-to-dashboard navigation at desktop and mobile sizes.
